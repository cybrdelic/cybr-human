# Provenance and license status

No blanket repository license is granted or invented here. Public release needs an owner/license review even though the runtime data are excluded.

## Source categories

- **Project-local authored/adapted:** the mechanics/contact and renderer snapshots contain project-specific implementations and tests. This describes their provenance in the working project, not a verified author list or copyright assignment.
- **Inherited project sources:** parent mechanics.py/current_tangent.py, finite_closed_contact.py and unified/deformable contact modules predate the selected snapshot. They are independently inventoried and must not be presented as newly authored v14 files.
- **Imported archived helpers:** geometry/helpers/build_reference.py and free_skin.py explicitly identify themselves as pure helper subsets extracted from archived source. Other geometry helpers are inherited. Their complete upstream author/license chain was not established.
- **Upstream anatomy/data, excluded:** local anatomy metadata declares “CC BY-SA4.0, BodyParts3D / Z-Anatomy; retained source attribution,” identifies a native source blend SHA, and records historical registration plus authored gum/cranial changes. This is a **metadata-declared attribution**, not independent verification that every source, component, derivative or proposed redistribution is covered.

No LICENSE/COPYING/NOTICE document establishing a blanket source grant was found in the inspected project tree. Do not infer that code inherits the anatomy's declared license, that all helpers are original, or that source-only distribution resolves every provenance issue.

Before public publication: identify the code owners and intended license; locate authoritative upstream versions/attribution for anatomy and imported helpers; check obligations for any derivative data or source chosen for distribution; retain applicable notices and change records. Keep anatomy and historical artifacts outside Git until separately cleared. The repository may remain private during this review, but private visibility itself is not a license grant.
