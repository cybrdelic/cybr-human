# Regional optical candidate

Isolated flags: `appearance=regional` and `eyeOptics=refractive`, independently selectable. The combined release candidate defaults to Refined; Classic selects the former response. No tissue parameters, geometry, muscle model or diffusion kernel changes.

The regional skin uses white dielectric specular reflectance with IOR 1.4 (normal-incidence F0 approximately 0.0278), while separating the same diffuse radiance for existing screen-space transport. NVIDIA's [human skin rendering chapter](https://developer.nvidia.com/gpugems/gpugems3/part-iii-rendering/chapter-14-advanced-techniques-realistic-real-time-skin) supports spatially varying skin response and this optical approximation. Its measured Beckmann roughness values are not copied into this renderer's GGX roughness. Here face 0.6, nose approximately 0.45, lips 0.3 and transition widths are authored parameters awaiting visual testing, not measured subject calibration.

Lip coverage follows the upper/lower rest-shape mouth construction rather than one constant-width band. Fields are evaluated after authored shape deltas and advect with material vertices. One float attribute adds four bytes per skin vertex; colors and existing deterministic micron relief remain. No photos, textures from external subjects, or generated assets.

Optional cornea uses the existing spherical cap, IOR 1.376, transmission 1 and approximate thickness 0.55 mm. [This optical worked example](https://www.gatinel.com/recherche-formation/paraxial-optics-for-iol-power-calculation/paraxial-optical-power-of-the-cornea/) provides those approximate optical dimensions. It is not an individualized eye fit. Removing the extra clearcoat avoids doubling the surface specular lobe. Three.js screen-space transmission can add opaque scene passes and render targets; its latency, memory, ordering, pupil/limbus appearance and diffusion interaction must be measured independently before adoption.

CPU field contracts and source syntax are verified. The isolated optical candidate passed actual shader/runtime checks and studio/side/overhead comparisons of all four flag combinations in neutral/passive/pull states. All states converged; maximum sampled position-component difference was 0.166 micrometres. Regional lips are more distinct, but waxy response and authored eye transitions remain. A later paired neutral four-sample coverage capture reduces edge steps and brow speckling without changing sampled positions. These passes do not establish optical accuracy, general startup/throughput improvement or total memory. Combined default interaction/recovery acceptance remains pending; see COMBINED-RELEASE.md. Previous immutable candidates and selected live runtime remain preserved.
