# Consolidation decisions

This standalone source package was curated from two local copies of the face project, previously maintained inside the parent `cybr-geo` repository. The selected immutable runtime is **4bc8b53a8f15b8b62cf6a86e**. The original working trees and local evidence remain preserved separately.

## Included

- Supported HTML entry and legacy redirects; editable viewer, workers, shaders and construction tools.
- Reusable numerical and browser tests, with their small solver fixture.
- One selected immutable runtime and its required model/binding/geometry assets and notices.
- Minimal licensed internal atlas selection, current construction intermediates and attribution.
- Pinned dependency declarations and the required local Three.js module closure.

The comparison found no unique non-output source in the secondary copy. The retained runtime publisher includes an existing copy fallback for systems that cannot create hard links. Current pointers and selected manifests agreed. Experimental rigs, imported exterior/photo references, historical research, old runtimes and generated iteration histories do not enter the supported source/dependency graph.

Editable surface-cache, bounded-CG, viewer-scheduling and lip-shading work remains separate from the older selected runtime. Historical candidate **ef7aee6716ff02e2cc0021f9** was not promoted or included as the active build. See REPRODUCIBILITY.md.

## Tooling cleanup

Tests accept `TISSUE_BASE_URL`; the manager supports offline/browser suites and an explicit server port. Reusable checks write ignored `output/verification/` results. Query construction and former dated output locations were cleaned up. No solver equations, selected shaders, HTML UI or runtime bytes were redesigned.

## Public boundary

Private backups, browser profiles, cookies/auth state, credentials, caches, installed dependencies, raw QA reports and captures are excluded. Local comparison reports containing personal paths are excluded. Public provenance records contain relative project paths and hashes only. Required numerical NPZ/GLB/binary assets remain included; the source atlas ZIP and Blender project are not shipped.

The hash contract is SHA256 of sorted relative path, NUL, file SHA256, and LF. `provenance/staged-source.json` retains initial source-copy evidence without host paths. `provenance/public-source.json` describes the curated public package and excludes itself.
