# HUMAN preferred-head and mechanics checkpoints

This bounded addition complements the existing application; it does not silently change its browser runtime or replace its licenses.

- `checkpoints/preferred-v53`: self-contained exact reconstruction of the selected rough original rest head and semantic topology.
- `appearance`: separately maintained conditioned optical runtime, with explicit optional orbital/margin candidates.
- `mechanics/regional-reference`: original checked regional bone/muscle/passive-insertion proofs, exact saved arrays and editable source.
- `mechanics/attachment-audit`: focused exact-root and static contact infrastructure tests. The new broad-domain expression experiment is not promoted here.

Run `python verify_integration.py` for payload hashes, safe source compilation, saved-state sanity and focused attachment tests. Run the preferred build command in its README to reproduce the exact dense head. Each optional appearance profile must declare its input geometry explicitly.
