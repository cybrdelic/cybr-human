# Experimental exact attachment/contact infrastructure

These seven helper modules are included under the regional workspace's `human-preferred-v53-anatomical-assembly-20261011/resumed-source` directory. They are tested infrastructure, not an accepted integrated expression state.

```
node mechanics/regional-reference/workspace/human-preferred-v53-anatomical-assembly-20261011/resumed-source/test_parameterized_bonds.mjs
```

The focused tests cover rational source-triangle root correspondence, exact positive rigid gaps, target/bone/trajectory invalidation and rejection of actual intersections. A sub-margin exemption is valid only when both triangles remain completely fixed for the entire permitted state family. Moving faces retain the full swept clearance requirement. Future jaw/bone motion invalidates these static tokens.

The original 41,027-cell neutral reference was reloaded with 477 root faces, neutral J=1, residual 9.63e-18 and zero stress-free contact energy. The complete rest audit still found four moving clearance failures at three points, so this historical diagnostic is not a globally admitted moving case. `report.json` records the failures. No arbitrary force residual was subtracted: the positive-stiffness contact reference uses each actual positive rest gap.

The newer broad foundation, activation and fine-skin transfer are outside this published checkpoint until their force-path, contact and whole-face gates pass.
